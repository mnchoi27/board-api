# board-api

A REST API for a simple bulletin board where members can create and manage posts and comments.

## Tech Stack

- Java 25
- Spring Boot 4.1
    - Spring Web MVC
    - Spring Data JPA
- H2 Database
- Gradle (Groovy DSL)
- springdoc-openapi

## Getting Started

### Prerequisites

- JDK 25

### Run

Clone the repository and run the application with Gradle Wrapper.

```bash
./gradlew bootRun
```

The application will be available at:

http://localhost:8080
